# Juhui Seo — portfolio

Static site: `index.html` (home), `idexx.html`, `nstem.html`, `miles.html`, served with clean URLs on Vercel (`/idexx`, …).

- `dc-lite.js` — small runtime that renders each page's `<template id="dc">` and runs its `<script type="text/x-dc">` logic.
- `assets/` — images and videos.
- `vercel.json` — clean URLs and caching.

Local preview: any static server with clean URLs, e.g. `npx serve .`
